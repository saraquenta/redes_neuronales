# Redes Neuronales en Mortales · Laboratorios de las secciones 14 y 17.1

Laboratorios interactivos enlazados desde los códigos QR del libro *Redes Neuronales en Mortales*.

Sitio: https://saraquenta.github.io/redes_neuronales/

| Sección | Laboratorio | Dirección |
|---|---|---|
| 14.1 | Dibuja un número y mira qué piensa la red | https://saraquenta.github.io/redes_neuronales/c2/digitos/ |
| 14.5 | Una red que lee números escritos a mano | https://saraquenta.github.io/redes_neuronales/c2/cuaderno-digitos/ |
| 17.1 | ¿Qué red usarías? | https://saraquenta.github.io/redes_neuronales/c2/tipos-de-redes/ |

Páginas HTML estáticas, sin servidor ni recolección de datos. El código fuente está en `fuente/` (ejecuta `python3 fuente/site.py`).

**No cambies las direcciones `c2/...` ni `cuadernos/...`: están impresas en el libro.**
